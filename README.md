## What it does

Paste a code and The Code Translator tells you what it is, then translates it as you type. It works the other way too: type ordinary words and it turns your message into code.

Try it: `01001000 01101001` decodes to **Hi**. [Open the binary code translator →](https://thecodetranslator.com/binary-code-translator/)

## Features

- **Free, no sign-up, no daily limit.** Works the same on a phone as on a computer.
- **Translates as you type.** No Convert button and no waiting.
- **Detects the code for you.** Recognizes 8-bit, 7-bit and UTF-8 binary.
- **Checked against the standard.** Examples are verified against ASCII and UTF-8 (RFC 20 and RFC 3629).
- **Emoji and accents.** Handles é, ñ, 😀 and other languages, not just plain English.
- **Share a decoded link.** Send a link that opens your message already translated.
- **Private by design.** Everything runs in your browser. Nothing you type is uploaded or stored.

## Code or cipher?

A **code** swaps each letter for a fixed symbol, so anyone with the chart can read it (binary, Morse, Braille). A **cipher** scrambles letters by a rule or key, so you need the key to read it (Caesar cipher).
